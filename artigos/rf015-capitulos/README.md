# Post do Substack — Capítulos no TaleCraft

Rascunho pronto para colar no editor do Substack.

## Arquivos

- `post.md` — texto completo, já com os marcadores de imagem.
- `imagens/capitulos.jpg` — quadro de capítulos (sugestão de capa).
- `imagens/capitulo-edicao.jpg` — painel de edição aberto.
- `imagens/capitulo-personagens.jpg` — personagens do capítulo com evento e motivo.
- `imagens/icone-256.png` — ícone do TaleCraft, se quiser usar como miniatura.

## Como publicar

1. No Substack, crie um novo post em branco.
2. Copie o conteúdo de `post.md` (do título até o fim) e cole no editor.
3. Apague a linha `**Subtítulo:**` e use o texto dela como subtítulo do post.
4. Nas três posições marcadas com `![...](imagens/...)`, faça upload do arquivo correspondente.
5. Remova as linhas de legenda em itálico se o Substack já permitir legenda na imagem — ou mantenha, funciona como texto normal.
6. Use `imagens/capitulos.jpg` como imagem de capa do post.
7. Agende ou publique.

## Observações

- As capturas são do aplicativo real, com banco de demonstração isolado e dados de exemplo do livro *A Órbita Silenciosa*. Nenhum dado de usuário foi usado.
- As imagens estão em JPEG na resolução de captura (2400×1500 no quadro; o painel tem recorte mais alto). O Substack aceita esse formato.
- O texto está em português; se quiser uma versão em inglês, é só pedir.
